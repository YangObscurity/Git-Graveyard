# Bundled fonts

These fonts are bundled so `next/font/local` builds without network access. Each file is the Latin subset with a variable `wght` axis, taken unmodified from the Fontsource npm packages (version 5.3.0).

| File | Family | Source package | License |
|---|---|---|---|
| `AtkinsonHyperlegibleNext-latin-wght.woff2` | Atkinson Hyperlegible Next | `@fontsource-variable/atkinson-hyperlegible-next` | SIL OFL 1.1, `OFL-AtkinsonHyperlegibleNext.txt` |
| `AtkinsonHyperlegibleMono-latin-wght.woff2` | Atkinson Hyperlegible Mono | `@fontsource-variable/atkinson-hyperlegible-mono` | SIL OFL 1.1, `OFL-AtkinsonHyperlegibleMono.txt` |
| `GrenzeGotisch-latin-wght.woff2` | Grenze Gotisch | `@fontsource-variable/grenze-gotisch` | SIL OFL 1.1, `OFL-GrenzeGotisch.txt` |
